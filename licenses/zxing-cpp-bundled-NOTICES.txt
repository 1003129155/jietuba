zxing-cpp 3.1.1: code compiled into the Python module besides zxing-cpp itself

The zxing-cpp wheel ships only zxing-cpp's own Apache-2.0 license. Its module also contains
libzint (barcode writing, from zint/backend) and libzueci (ECI conversion); their notices,
taken from the zxing-cpp 3.1.1 sources, follow. Update this file together with zxing-cpp.
