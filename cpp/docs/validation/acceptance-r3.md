### 10.1 旧版一键更新到 C++ 单文件版

用 2.1.6 轻量版包里内嵌的更新器（0.2.1，从单文件包里原样取出），对一个运行中的 2.1.6 轻量版执行 `apply`：

- 安装目录只有 `jietuba_lite.exe`（2.1.6）。测试 ZIP 根目录只有一个 `jietuba_lite.exe`，内容是 C++ 静态单文件版；它只依赖系统 DLL（Media Foundation 延迟加载）。
- 缓存按 `download` 的产出准备（`app.exe` + `prepared.json`）。**GitHub 下载这一步没有测**：更新器只认 HTTPS，在公开仓库建预发布虽然不进 `releases/latest`，但会通知关注发布的人，所以没有建。
- 结果：交接事件 `ready → handed_off`；旧版退出后安装目录的 exe 换成了 C++ 版（哈希一致），并从原路径自动启动；C++ 版读到原来的设置（日志写进设置里指定的目录，界面中文，剪贴板历史上限 1000），热键注册成功；worker 结果 `complete`，`.jietuba-update/<事务>/` 留有 `backup.exe` 和阶段为 `complete` 的事务日志，可回滚。
- 结论：「旧更新器只换 exe」对静态单文件版成立。轻量版改用 C++ 发布时，包名沿用 `jietuba_lite-<tag>-<arch>.zip`、根目录放 `jietuba_lite.exe` 即可接上；版本号需要高于已发布的 Python 版。
