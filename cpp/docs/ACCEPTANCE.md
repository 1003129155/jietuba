# 整机验收清单

C++ 版替换 Python 版之前，在同一台机器上两边按本清单逐条操作、对照结果。逐函数对照和自动测试见 [MIGRATION.md](MIGRATION.md)，这里只看用户能看到的行为和升级路径。

## 做法

- 一次只开一个版本。两边共用设置、热键和剪贴板库，同时开着会抢热键，剪贴板历史会被写两遍。
- Python：在 `..\main` 下运行 `..\venv311\Scripts\python.exe main_app.py`。C++：`run.cmd`（`dist\Release`），单文件版是 `dist\Release-static\jietuba_lite.exe`（10-15 之前叫 `jietuba_cpp.exe`）。
- 同一条先跑 Python 再跑 C++。Py、C++ 两栏填 ✓（符合）、✗（不符，备注写现象）、—（不适用）。
- 两边一致但都不对的，算原版 bug，按 AGENTS.md 先修 Python。
- MIGRATION.md「与原版的差异」里登记过的偏离（如截图窗口每次新建、启动先注册热键）按登记的结果判，不算不符。
- 优先级：**P0** 日常主流程，切换前必须全过；**P1** 常用功能；**P2** 环境与边角。
- 每轮开头记下环境：系统版本、显示器数量、分辨率与缩放、是否开 HDR、测的是哪个提交。
